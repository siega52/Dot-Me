**Dot Me** — современный персональный сайт-визитка Frontend-разработчика. Проект выполнен на React + Vite с анимированным фоном и музыкальным плеером.

## Особенности

- **Анимированный фон** — плавное переключение между 3 фоновыми видео с эффектом затухания
- **Музыкальный плеер** — полноценный плеер с регулировкой громкости, перемоткой и переключением треков
- **Стек технологий** — визуальное отображение всех используемых технологий в виде стильных карточек
- **Адаптивный дизайн** — корректное отображение на всех устройствах от десктопов до мобильных телефонов
- **Glass-card** — современный дизайн с эффектом стекла (blur) и плавными анимациями

## Технологии

- **Frontend**: React 19, TypeScript
- **Сборка**: Vite 4.4
- **Стилизация**: CSS с анимациями и медиа-запросами
- **Иконки**: React Icons
- **Деплой**: GitHub Pages
